# EraRelay v0.5.5 · 可靠性增强

本版为常规正式版，重点改善会话生命周期、连接隔离与显示恢复；不将本版描述为性能升级，也不宣称全部问题已修复。

## 更新内容

- 会话生命周期：先准备和校验候选路径，再进行会话替换；加强启动取消、资源回收与生命周期控制门禁。
- 连接隔离：旧连接或旧操作的迟到回调不应干扰新连接；恢复请求增加会话与请求归属检查。
- 显示恢复：协议更新为 v14，快照与增量带会话身份和显示/状态水位；显示与顶层输入状态分别校验，减少重复显示和旧状态倒灌。
- 订阅时序：建立订阅后再启动会话，补强首帧接收链路。
- **仅 HTTP 模式的退出反馈**：按服务端退出契约确认后再清本地状态；拒绝、超时或未确认时显示反馈，并提供重试或仅离开页面。**MAUI 原生退出流程未改动**。
