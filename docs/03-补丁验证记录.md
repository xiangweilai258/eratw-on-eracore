## 三、一个需要说明的细节

### 反向 check 会「失败」，这是正常的

```bash
git apply --reverse --check eratw-EE56-compat.patch   # 在「已打补丁」的副本上跑
# → error: patch failed: ...PluginManager.cs:266
# → error: patch failed: ...EESqlRuntime.cs:1
```

**这不是补丁缺陷**，原因有二：

1. `EESqlRuntime.cs` / `Creator.Method.EE56.cs` 是**新增文件**。反向应用意味着**删除**它们，  
   但反向 check 只做 dry-run，无法「先删再验」→ 报错
2. 前一处的失败会让 `git apply` 在处理多文件补丁时提前终止

**正确做法是正向验证**（从干净基线应用），见第二节 —— 已全部通过。

## 六、NF 指令族补全（2026-09-29 追加）

### 6.1 背景

eraTW 汉化整合版**自己 fork 的解释器 v9** 扩展了一组「不夺窗口焦点」的输入指令  
—— **NF（NoFocus）族**：`TINPUTNF` / `TINPUTSNF` / `TONEINPUTNF` / `TONEINPUTSNF`。  
eraTW 的动态地图动画依赖它，而上游 `era-core` 的 `main` 分支没有。

本次补齐这 4 个指令，产出 `patches/nf-input-family.patch`（**+108 / -4，5 文件**）。
