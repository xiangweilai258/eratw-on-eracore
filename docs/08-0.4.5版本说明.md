# 08 · v0.4.5 版本说明

> 相对 v0.4.4 的变化。上一版见 [`07-0.4.4版本说明.md`](07-0.4.4版本说明.md)。
>
> ★ **发布日期：2026-10-09**（北京时间）

---

## 一、可点的字，看得见了

★ **问题**：eraTW 有些界面会把选项文字设成**和背景一样的深色**（黑底黑字），玩家**看不出哪里能点**。

★ **为什么在手机上特别要紧**：

| | |
| --- | --- |
| 电脑上 | 鼠标划过去，那一条会高亮 —— 还能找到 |
| ★ **手机上** | ★ **根本没有「划过去」这个动作** ⇒ 用手机的人**永远看不到**那些选项 |

★ **本版做法**：自动检测 —— **只在「字很暗 且 背景也很暗」时**，给那个按钮补一层**很淡的底衬**。

| 情况 | 行为 |
| --- | --- |
| 黑字 ＋ 黑底（真看不见的） | ★ 补一层淡底衬 |
| 黑字 ＋ 浅底（本来就最清楚） | ★ **一点都不动** |
| 没设颜色的普通按钮 | ★ **一点都不动** |

★ **不加开关** —— 该出现时才出现，正常界面跟以前**完全一样**。

★ **性能**：判断是纯计算，**不去读**浏览器里元素的实际颜色（那会强制重算布局）；且只在换画面时算一次，**不是每帧算**。

## 二、说明：这不是「修 bug」

★ 我们对着**原版**逐项验证过：**原版也是黑字**，靠「鼠标移上去变黄」让人看见 —— 那本来就是给鼠标设计的。
★ 我们给手机的是**常驻**的淡底衬（不依赖悬停）⇒ 这是**给触屏补的替代方案**，不是「把原版弄坏的东西修回来」。

## 三、已知问题（下一版处理）

★ **eraTW 的「背景图片补丁」目前不生效** —— 开启后背景仍是黑的（原版会显示一张实景照片）。

★ **原因**：eraTW 的背景图走的是引擎的**精灵（SPRITE）绘制**那条路，而**这条路径我们还没实现**。
（立绘走的是**另一条路** —— 图片段，所以**立绘显示正常**，只有背景图受影响。）

★ **计划**：下一个版本 **v0.5.0** 以**插件适配**为重点，这一项会在其中解决。

★ 其余功能不受影响。
