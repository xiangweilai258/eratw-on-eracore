# EraRelay v0.5.7 · 输入锁与立绘兼容修复

本版修复连续推进画面输入完成后可能额外等待约 30 秒的问题，并改善部分资源文件名 Unicode 写法不一致导致的图片无法读取；不宣称全部问题已修复，也不承诺修复素材真正缺失。

## 【重要修复】连续推进额外等待约 30 秒

连续出现「点任意处 / 按回车继续」等画面时，输入完成后界面可能仍额外等待约 30 秒才继续。该缺陷引入于 0.5.5，0.5.6 亦受影响，建议相关版本用户更新。

修复方式：每笔输入携带请求身份，游戏侧消费该笔输入后原样回执，界面凭匹配身份立即继续。发送失败、被明确拒绝与结果未知分别处理；结果未知时先确认状态再放行后续输入，不自动重复提交。

## 【图片兼容】资源文件名 Unicode 写法不一致

部分资源文件名的内部 Unicode 写法与请求不一致（同一字符存在多种等价写法）导致图片读取失败、立绘破图。现读取资源时按「精确优先 + 唯一规范等价回退」解析，多候选歧义时拒绝而不是猜测。**不承诺修复素材真正缺失**，也不声称所有破图已由用户逐项验证。
