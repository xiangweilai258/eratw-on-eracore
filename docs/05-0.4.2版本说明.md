## 一、前端交互（装上去能直接看到）

| # | 变化                    | 为什么                                                                                                 |
| - | --------------------- | --------------------------------------------------------------------------------------------------- |
| 1 | ★ **输入栏改到屏幕右半边**      | 原来输入栏横跨整个屏幕底部，会盖住游戏输出末尾。而 Emuera 类游戏的**按钮与选项恰好打印在那里** → 玩家会点不到唯一能推进的输入。改成只占右半边后，选项区（实测全部落在左半边）不再被压住 |
| 2 | **推进提示也移到右半边**        | 与输入栏同一侧，视觉统一                                                                                        |
| 3 | ★ **「回到游戏」返回时自动回到底部** | 之前从设置／调试页返回，画面停在**最旧的一行**，每次都得手动划到底                                                                 |
| 4 | **文本区底部留出一行余量**       | 末行原来紧贴屏幕底边，还会被输入栏压住                                                                                 |
| 5 | **设置页分成两档**           | 「游戏相关」／「高级设置」，默认落在前者                                                                                |
| 6 | **设置项说明改成人话**         | 原来部分说明是逐字堆术语（含 100+ 字的纯技术描述、直接把配置字段名甩给玩家），现统一为「一句人话 ＋ 括号里放细节」                                       |
| 7 | **视图标签改名**            | 游戏内右上角设置里的 `Terminal` → **「回到游戏（Terminal）」**                                                        |
| 8 | **应用名改为 EraRelay**    | 桌面图标显示的名字。★ 包名 `com.eracore.maui` **保持不变** —— 改包名等于换一个应用，老用户会装不上、私有数据全丢                             |

## 二、打包链修复（你看不到，但它决定你拿到的包对不对）

| # | 问题                                                                             | 修法                                                                      |
| - | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| 1 | **干净仓库上第一次构建，APK 里前端资源为 0 条**（构建日志却显示「0 错误 0 警告」，装上去是 `ERR_NAME_NOT_RESOLVED`） | 改为在复制完成后**动态登记**打包资产，不再依赖构建期的 glob 展开                                   |
| 2 | **前端产物在 `wwwroot` 里越积越多**（文件名带内容哈希，旧文件永久残留并一起进包）                               | 复制前**整目录清空**（它完全是构建产物）                                                  |
| 3 | ★★ **APK 里打进旧前端**（日志无报错、签名正常、四个自检全过，**界面却是旧的**）                                | 构建前清 Android 资产暂存目录；★ 并在构建后**自动拆包比对** `assets/wwwroot` 与前端产物，不一致就以非零码退出 |

> ★ 第 3 条最阴险：它**完全不报错**。所以现在多了一道**自动**判据，不再靠人记得去拆包核对。

## 四、已知问题（未修）

- **横竖屏切换后不重新计算缩放**：游戏窗口宽度取自游戏的 `emuera.config`（eraTW 为 1800），旋转屏幕后该宽度不会重算 → 竖屏下内容会横向溢出、需要左右滚动。
- **内存**：退出游戏后约 770 MB 不立即释放（Windows 侧已量化，根因尚未定位）。
- 「点任意处继续」提示条的**点击穿透**尚未在真机上验证。
