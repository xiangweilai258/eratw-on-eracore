# EraRelay 使用说明

> EraRelay = eraTW on EraCore：把 eraTW 移植到 EraCore 引擎上运行。
> 仓库名 `eratw-on-eracore` 说的是「这是什么」，EraRelay 是这个项目的名字。

---

## 一、用现成 APK（最省事）

### 1.1 前置条件

- Android 设备，**arm64 真机**或 **x86_64 模拟器**（当前发布包为双架构，两者皆可）
- 一份 **eraTW 游戏目录**（本仓库不提供，见第三节）

### 1.2 步骤

1. 到本仓库的 **Releases** 页面下载 `EraRelay-v*.apk`
2. 允许「安装未知来源应用」，安装
3. 把 eraTW 游戏目录放到设备上，例如：
   ```
   /sdcard/emuera/eraTW/
   ├── ERB/
   ├── CSV/
   ├── plugins/            （如游戏自带）
   ├── pluginsAware.txt    （如游戏自带，可留可删——见下方说明）
   └── emuera.config
   ```
   > 用数据线拷、或先用文件管理器解压都行。

   > **关于 `pluginsAware.txt`**：这是旧版 Emuera 用来确认「我知道这游戏带了第三方插件」的标记文件。
   > **EraRelay 不依赖它**——有没有都能正常启动。
   > - **没装插件**的游戏：这个文件无关紧要，放着或删掉都可以。
   > - **带了插件**的游戏（如 eraTW 画蛇添足版自带 `plugins/`）：启动后画面会显示一条提示
   >   「检测到外部插件已启用……」，这是**正常提醒，不是错误**，点掉继续玩即可。
   >   不想要这条提示，可在 环境设置 → 相关项里关掉（配置名 `PluginAvailableWarn`）。
4. 打开应用，选择该目录，等待加载

首次加载约需十几秒（3931 个 ERB 文件解析）。之后有 IR 缓存，会快很多。

## 二、从源码构建

### 2.1 环境

- .NET 10 SDK
- Android SDK + JDK 17+（`JAVA_HOME`）
- 若要 NativeAOT，另需 C++ 工具链

### 2.2 步骤

```bash
# 1. 取上游源码
git clone https://github.com/LaoBro/era-core.git
cd era-core
git checkout main

# 2. 应用移植补丁
git apply /path/to/port/eratw-EE56-compat.patch

# 3. 构建（arm64 Release）
dotnet publish EraCore.Maui/EraCore.Maui.csproj \
    -f net10.0-android -c Release -r android-arm64
```

产物在 `EraCore.Maui/bin/Release/net10.0-android/android-arm64/publish/` 下。

### 2.3 用仓库脚本构建

```bash
bash tools/build-android.sh Release     # 或 Debug
```

脚本已内置 Debug 打包的一个坑的修复（见 `docs/01-移植技术报告.md` §7.1）。

### 2.4 在 PC 上跑（无头 / 浏览器）

```bash
# 无头引擎探针（量化加载耗时、打印画面、发送输入）
bash tools/eracore-probe.sh load
bash tools/eracore-probe.sh screen
bash tools/eracore-probe.sh input 0 1 1

# 浏览器方式
bash tools/start-web.sh 8080
```

## 四、常见问题

### Q：读档时偶尔报「变量未定义」并中断？

**已知偶发问题，重试即可。**

现象：读档时弹出类似 `变量"L_Time"未在此函数中定义（SYSTEM.ERB）` 的错误并中断流程。
实测在荣耀 ROD-W09 上为新旧存档各测 3 次共 6 次，均未复现；仅出现过 1 次崩溃记录，**属偶发**。

**绕过方式**：**重启游戏后重新读档**，或直接点掉该错误继续。不必重装、不必重下存档。

> 初步定位：eraTW 的 `SYSTEM.ERB` 存在**两个 `@EVENTLOAD` 标签**（一处带 `#LATER`），引擎把它们存为
> 独立分组、各自持有独立的私有变量表，第二组查不到第一组声明的变量。属引擎侧已知的
> 分组私有变量未跨组合并问题。尚未修复，后续版本处理。

### Q：地图没有动画？

**已知未实现**，动态地图依赖的 NF 指令族尚未补齐。

**绕过方式**：把地图类型设为「[2] 颜色地图」或「[3] 经典」。  
（在游戏内 环境设置 → 地图 相关选项里；该设置是 `SAVEDATA`，随存档持久化）

### Q：启动就闪退（Debug 构建）

Debug 构建在支持 fast-deploy 的设备上默认不把程序集嵌入 APK，导致原生库被压缩、启动失败。

**修复**：用 Release 构建，或用 `tools/build-android.sh`（已内置该修复）。

### Q：加载很慢

首次加载需要解析 3931 个 ERB 文件。首次之后会生成 IR 缓存，第二次起明显加快。

若缓存损坏或想强制重建，删除游戏目录下的 `_IRCache/`。

### Q：启动后画面显示「检测到外部插件已启用」？

**正常提示，不是错误，点掉继续玩即可。**

完整文案是：

> 注意：检测到外部插件已启用。插件由第三方提供，由此产生的问题不在本引擎支持范围内；
> 如非你本人安装，请检查游戏目录下的 plugins 文件夹

**为什么会显示**：游戏目录下的 `plugins/` 里有 DLL 插件（例如 eraTW 画蛇添足版自带的数学插件）。
引擎检测到插件就会提示一次，用于**告知**插件由第三方提供、风险不在引擎支持范围内。

**要不要处理**：
- 插件是你自己装的 / 游戏自带的 → **不用管**，这是知情提醒。
- 目录里有你不认识的 DLL → 按提示检查 `plugins/`，确认来源可信。
- 就是不想看到这条提示 → 在**环境设置**里关掉「外部插件警告」（配置项 `PluginAvailableWarn`）。

> 顺带说明：这条提示**不影响启动，也不影响插件功能**——插件照常可用。
> 早期版本曾在此处直接拒绝启动（要求手工创建 `pluginsAware.txt`），现行为已对齐上游 Emuera 的软警告方案。

### Q：某款其他 era 游戏跑不起来？

本补丁是针对 eraTW 的 EEv56 扩展做的适配，**不保证**其他使用 EEv56 的游戏都能跑。  
其他游戏如遇问题，欢迎提 issue 并附上错误日志。

### Q：插件加载失败

`EraCore.Core` 已对旧程序集标识（`Emuera` / `Emuera.EM` / `EraCore`）做自动重定向，  
并对无法加载的类型降级为警告。若仍有问题，请附上完整日志。

## 五、日志与排障

| 内容     | 位置                                                       |
| ------ | -------------------------------------------------------- |
| ★ 游戏/引擎错误 | 游戏目录下的 `emuera.log`（**含精确行号、错误内容、函数名、调用栈**，最有用） |
| 崩溃日志   | `/sdcard/eracore-crash.log` 或 `Android/data/<包名>/files/` |
| SQL 诊断 | 产物目录下的 `sql-debug.log`（异常）/ `sql-connect.log`（连接记录）      |

> ⚠️ **引擎异常通常不落 `adb logcat`** —— 被捕获后只写入画面与游戏目录下的 `emuera.log`。  
> 遇到问题**优先看 `emuera.log`**，它比 logcat 和截图都精确。

> ⚠️ 部分 OEM 设备（如华为 / 荣耀）用自有日志系统，`adb logcat` 可能读不到应用日志，  
> 此时以设备上的崩溃日志文件为准。

### 常用 adb 操作

```bash
# 看设备
adb devices -l

# 读游戏侧错误日志（★ 最有用，注意 Git Bash 下要写双斜杠）
adb shell cat //sdcard/emuera/eraTW/emuera.log

# 看存档目录时间戳（判断走的是新游戏还是读档）
adb shell ls -la //sdcard/emuera/eraTW/sav

# 内存采样
bash tools/soak-memory.sh 60 60      # 60 分钟，每 60 秒一次
bash tools/soak-v2.sh 180 30         # 含 WebView 渲染进程

# 跨架构基准
bash tools/bench-app.sh <包名> <Activity组件> 60
```
