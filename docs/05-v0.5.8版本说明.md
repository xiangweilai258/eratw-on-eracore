# EraRelay v0.5.8 · 启动字符雨与手机布局优化（Android + Windows）

本版首次同时提供 Android 与 Windows 两个发行物。新增约三秒启动字符雨，优化手机短横屏首页，修复菜单滚动与剧情页贴底问题，并改善多层合成立绘的显示。不宣称所有游戏、所有设备问题已全部解决。

## 【新增】启动字符雨

打开应用时播放约三秒的字符雨动画，结束后自动进入模拟器的游戏选择首页；首页初始化与游戏扫描照常进行。

## 【优化】手机短横屏首页

压缩横屏首页留白，选目录入口更容易点到。

## 【修复】右上角菜单滚动

菜单滚动时不再带动背景页面，部分原本无法到达的选项现在可以滑到。

## 【适配】Android 安全区

改善刘海/挖孔与系统栏造成的边缘留白和转屏布局。

## 【修复】剧情页自动贴底

部分剧情页面出现新输出后现在会自动贴底，不再需要手动补滑才能继续；主动上翻阅读历史时仍保留位置，回到底部后恢复跟随。

## 【改善】多层合成立绘

改善部分多层合成立绘的显示、裁切与透明度处理。**不承诺所有缺图或所有游戏问题全部解决**；素材真正缺失仍无法凭空补出。

## 【更新】SQLite 原生依赖

更新到本轮验证过的版本；托管接口与存档格式没有为此变更。

## 【安装】

- Android **arm64**：与 0.5.7 同签名证书，可覆盖安装保留数据；建议先备份重要存档；**不要先卸载或清数据**——若提示版本或签名冲突，先反馈再处理；不保证所有设备安装零风险。
- **Windows x64**：完整解压 ZIP 后运行 `EraRelay\EraCore.Maui.exe`（.NET 与 Windows App SDK 自包含）。WebView2 使用系统现有运行时。发行包不含游戏与存档，不自动迁移、删除或覆盖玩家文件。

## 【验证边界】

- 启动动画、横屏布局、菜单滚动、自动贴底与合成立绘改善已由用户在实际设备上验证体验通过；不宣称所有机型、所有游戏、所有场景或长时运行性能均已验证。
- Windows 版已在验证环境启动并显示新手说明与游戏选择首页；未在无 WebView2 的干净系统验证。
- 本版 Android 为配置文件引导的 AOT（profile-guided），不是 NativeAOT。
