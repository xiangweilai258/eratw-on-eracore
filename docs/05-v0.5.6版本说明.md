# EraRelay v0.5.6 · SQL 会话隔离与目录引导修正

本版修复换游戏后 SQL 连接沿用旧数据库的问题，并纠正应用内目录选择引导；不将本版描述为性能升级，也不宣称全部问题已修复。

## 更新内容

- **修复换游戏后 SQL 连接沿用旧数据库的问题**：游戏会话结束时释放引擎持有的 SQL 连接与 reader，旧会话的连接不再被下一局同名连接复用（此前可能读写到旧游戏目录的数据库）。
- **纠正目录选择引导**：新手引导的目录示意图改为标注「装着游戏文件夹的父目录」，并说明应用会扫描该层列出其中的游戏；主目录为空时的提示改为「请将游戏文件夹放在主目录下，每个游戏文件夹中需包含 CSV 和 ERB 子目录」。

## 验证与边界

- 已有回归证据：前端 **38 文件 / 721 例全部通过**（含新增 8 例引导组件测试），类型检查通过；C# **1242 例 / 1240 通过 / 2 失败**，两条失败为既有 SAF 用例，不隐去也不称全绿。
- 本轮**未做 Android 真机动态验证**。安装包经静态核验：版本 0.5.6/506、applicationId `com.eracore.maui`、仅 arm64-v8a、签名 v1/v2/v3 有效且与 v0.5.5 同证书、APK 内前端资源与本次构建产物逐字节一致（含本轮目录引导文案）。真机验证与正式发布安排由用户与主模型裁定。
- 修复覆盖单活跃会话模型下经应用内换游戏的路径；不泛化为多会话并发安全。
- 本版不是性能升级，不宣称全部问题已修复。
