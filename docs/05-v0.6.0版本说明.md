# v0.6.0版本说明

本版沿用现有引擎，集中改进eraTW兼容和界面体验；不包含游戏文件。

## 改了什么

- 首页打开设置时由设置页接替列表，按当前页面层级返回，避免重复显示；设置、重扫与缓存操作的失败或结果未知会反馈。
- 文字衬底随文字样式保存，普通文字、按钮和HTML文字可以使用；关闭后保留既有文字的历史样式，并处理较旧WebView的颜色表达兼容。
- EXISTVAR按具体变量单元及下标检查存在性，保留下标表达式内部错误；TRYCCALLSTR满足当前游戏的单字符串表达式、无目标实参用法，不代表整个调用指令家族已兼容。
- 消除同一次行布局的重复计算，补齐SQL失败路径的资源释放。没有量化本版提速，不把资源清理称为SQL功能扩展。
- 保留已有合成显示、启动动画、手机紧凑首页/菜单滚动与有限自动跟底。

## 范围与已知限制

音乐与游戏内Bad Apple动画明确暂不适配；快速施法/输入宏完整链、部分图形像素能力未在本版宣称完成。面向eraTW画蛇添足版，其他游戏未全面验证。

前端887例在兼容的Node测试宿主条件下通过；默认Node26的原生Web Storage会与DOM模拟器冲突，测试进程禁用该能力或使用Node24可通过，不改变玩家页面代码。

本次发行候选的引擎关键回归81/81通过，覆盖EXISTVAR、SQL失败清理、文字衬底、TRYCCALLSTR、设置写入失败与合成图。引擎既有两条SAF测试失败保留；新机全量同进程回归还存在共享静态状态/执行顺序问题，不能宣称全量全绿。源码隔离编译、分项回归与逐进程对照分别记录。本版Windows界面已检查首页/设置/返回与目录选择，用户手动确认自建场景的连续推进、底色历史保留和正常退出；不等于完整eraTW或所有菜单均验收。

Android真机、较旧WebView实机、长期内存与性能、全部游戏场景仍未全面验证。Windows ZIP完整解压后运行`EraCore.Maui.exe`，不附游戏或存档。
