# 06 · v0.4.3 版本说明

> 相对 v0.4.2 的变化。上一版见 [`05-0.4.2版本说明.md`](05-0.4.2版本说明.md)。

---

## 一、前端交互（装上去能直接看到）

| # | 变化 | 为什么 |
| - | ---- | ------ |
| 1 | ★★ **新增「方向锁定」，默认锁定横屏** | era 游戏的**画面宽度由游戏自己定**（本作是 1800px）。横屏 1920 正好放得下，而**竖屏 1200 会把右边一截裁掉** —— 之前玩家只能自己去调缩放。★ 现在默认就横过来 |
| 2 | ★ **新增「双指缩放」开关，默认开启** | 有的玩家容易误触双指手势、把画面缩走。关掉后手势完全不响应 |
| 3 | ★★ **右上角按钮排有了「收起 / 展开」把手** | 按钮会随功能变多而挤。收起后只剩一条**窄条**，点它再展开 |
| 4 | ★ **输入栏移到右上角（按钮排正下方）** | 原来贴着屏幕底部，会压住游戏输出末尾 —— 而这类游戏的**选项恰好打印在那里** |
| 5 | **推进提示（「点任意处继续」）也移到右上** | 与输入栏同侧，视觉统一 |
| 6 | ★ **四个悬浮按钮统一了半透明底** | 原来未激活的按钮在游戏画面上**只有图标、看不出是个按钮** |
| 7 | ★★ **新增「疑难解答」页** | 十条常用问答（白屏 / 游戏放哪 / 扫不到 / 卡顿 / 存档…）。★ **游戏内和主菜单的 ⋮ 里都能进** |
| 8 | ★★ **新增「新手引导」** | 首次进主界面**自动弹一次**，之后可点右上角 **?** 再看。含三块：游戏去哪找 / 怎么放 / 怎么玩 |

## 二、稳定性 —— ★ 这条是本版最重要的

| # | 问题 | 修法 |
| - | ---- | ---- |
| 1 | ★★★ **有些设备上打开是一片白**，什么都没有，玩家只能卸载 | 根因**不在本应用**：那些设备的系统「网页组件」残缺，导致网页渲染进程根本起不来 —— ★ 此时**前端代码一行都没执行**，所以只能在壳层兜底。现在等 **7 秒**收不到前端就绪信号，就盖一层**说明页**：一句人话 ＋ 三条可照做的修法 ＋ 「重试」「复制诊断信息」 |
| 2 | 那个等待原来是 **20 秒**，太久了 | 收到正常设备实测（就绪只要 **0.5 秒**）后收紧到 **7 秒** |
